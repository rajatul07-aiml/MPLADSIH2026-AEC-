# MPLAD SIH2026 Prototype V1 {TEAM AARAMBH}

## MPLADS AI Risk Intelligence System

An AI-assisted risk intelligence prototype for prioritizing MPLADS works for human verification.

The system combines:
- Machine-learning anomaly detection
- Rule-based risk analysis
- Similarity analysis
- Weighted risk aggregation
- Interactive risk monitoring
- Work-level explanations
- Alerts
- Inspection worklists
- Verification workflow
- Audit Trail
- New Work risk analysis

> **Disclaimer:** The risk score is a prioritization signal for human verification. It does not establish fraud, wrongdoing, or misconduct.

**Version:** V1

## Installation

### 1. Clone the Repository

```bash
git clone YOUR-GITHUB-REPOSITORY-URL
cd MPLAD-SIH2026-PROTOTYPE-V1
```

Replace `YOUR-GITHUB-REPOSITORY-URL` with the repository URL.

### 2. Backend Setup

```powershell
cd backend
python -m pip install -r requirements.txt
```

If FastAPI/Uvicorn are not already installed:

```powershell
python -m pip install "fastapi>=0.115,<1" "uvicorn[standard]>=0.30,<1"
```

### 3. Start the Backend

```powershell
python run_api_8003.py
```

Keep this terminal running.

Check:

```text
http://localhost:8003/api/health
```

If the launcher is configured for a different port, use the port printed in the terminal.

### 4. Frontend Setup

Open a second terminal:

```powershell
cd frontend
npm install
npm run dev
```

Vite will display a local URL such as:

```text
http://localhost:3000/
```

or:

```text
http://localhost:5173/
```

Open the exact URL shown by Vite.

## Machine Learning

The prototype uses an **Isolation Forest** approach for unsupervised anomaly detection.

Model artifacts are stored in:

```text

```

Including:
- `isolation_forest_pipeline.pkl`

- `score_normalization_params.json`

## Important Interpretation Note

This system prioritizes works for human verification.

A high or critical risk score should **not** be interpreted as proof of fraud, corruption, wrongdoing, or misconduct.

Risk signals should be reviewed by an authorized human reviewer before administrative action is taken.

## Prototype Limitations

This is an SIH prototype and not a production deployment.

Prototype-level limitations include:
- Large datasets may make some frontend operations slower.
- The frontend processes a large number of real work records.
- Inspection trend visualization depends on available inspection-date information.
- File-based persistence is used for verification and audit information.
- Production deployment would require additional infrastructure, security, monitoring, authentication, authorization, database hardening, and performance optimization.
